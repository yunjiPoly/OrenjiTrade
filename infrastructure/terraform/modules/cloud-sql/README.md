# module: cloud-sql

Cloud SQL for PostgreSQL 17, private IP only (Private Service Access), TLS enforced,
automated daily backups with point-in-time recovery, Query Insights, a maintenance window
and an application database + user. PostGIS and the other extensions are created by Flyway
(`V001__extensions.sql`), so the instance needs nothing else.

| Input | Default | Notes |
| --- | --- | --- |
| `instance_name` | — | e.g. `orenjitrade-dev` |
| `network_id` | — | from the `network` module |
| `tier` | `db-f1-micro` | prod: `db-custom-2-7680` or larger |
| `availability_type` | `ZONAL` | prod: `REGIONAL` |
| `deletion_protection` | `false` | prod: `true` (Terraform + API level) |
| `point_in_time_recovery_enabled` | `true` | |
| `transaction_log_retention_days` | `7` | |
| `retained_backups` | `7` | prod: 30 |
| `app_user_password` | — | sensitive; generated by the environment and stored in Secret Manager |

Outputs: `instance_name`, `connection_name`, `private_ip_address`, `database_name`,
`app_user_name`, `jdbc_url`, `database_id`.

The environment must add `depends_on = [module.network]` so the PSA peering exists first.
Restore procedures live in `docs/deployment/backup-restore.md`.
